# 비평 02 — 만든 맥락이 없는 서브에이전트의 판정과 반영

최종 렌더 1차 합성본의 1초 간격 시트만 주고 판정을 받았다.

## 받은 판정

| 장면 | 판정 | 지적 |
| --- | --- | --- |
| 인트로 s01 | 고침 | 최종값 1,076,767건이 한 장면에만 보인다 |
| 인트로 s02 | 고침 | 부제 글씨가 작다 |
| 인트로 s03 | 고침 | 노드·꼬리표 글씨가 작고 왼쪽 아래가 비었다 |
| 인트로 s04 | 유지 | |
| 인트로 s05 | 다시 만듦 | 영문 에이전트 이름을 읽을 수 없다. 확대 구간에서 카드가 잘리고 도장이 이름을 가린다 |
| 인트로 s06 | 유지 | |
| 인트로 s07 | 고침 | 메타 줄이 작다. 하네스 5종인데 부제가 과제 4개만 적었다 |
| 챕터 c1 | 고침 | 끝 화면에 다섯째 묶음만 강조된 채 남는다. `kac-classification-audit` 가 두 줄로 나뉜다 |
| 챕터 c2 | 유지 | |
| 챕터 c3 | 다시 만듦 | 끝 화면(슬라이드에 남는 화면)에 잘린 카드 두 장만 남는다 |
| 챕터 c4 | 유지 | 도장이 '반박·보완' 표시와 겹친다 |
| 챕터 c5 | 고침 | 제안 이름과 챕터 제목 크기가 비슷하다. 자모가 바뀌는 중간 글자(예: '좇')가 오탈자처럼 보인다 |
| 공통 | — | 클립 구간에 작은 '사례 N' 아래 큰 '사례 N'이 겹쳐 나온다 |

## 반영

- s01: 숫자 세기를 3.2초 → 2.5초로 줄여 최종값이 1.6초 이상 머문다.
- s02: 부제 30 → 34px.
- s05: 노드에 한글 역할명(23px, 예: 철 배정·배정 검증·배정 중재)을 크게, 영문 이름을 아래 작게 넣었다. 확대를 빼고 흐름에 쓰는 노드 다섯 개만 남기고 나머지를 흐리게 했다. 도장은 노드 위 빈 줄로 옮겼다.
- s07: 부제를 하네스 5종 이름(조직변경 영향도 · 기록물철 배정 · 분류 점검 · 조직 설계 · 단위업무명 제안)으로 바꾸고 메타 줄을 26 → 32px로 키웠다.
- c1: 6.6초 뒤 노드를 모두 채워 끝 화면을 고르게 했다. 하네스 이름이 한 줄에 들어가게 폭을 넓혔다.
- c3: 다시 만들었다. 카드 7장을 실제 결과 행으로 바꿨다(점검결과.csv, 배정결과.csv). 처음 만든 카드 4장은 표본 제목에 판정을 임의로 붙여 둔 것이었다. 카드가 지나간 뒤 두 하네스의 실제 집계(배정 제목 40개: 확정 33 · 확정(중재) 7 / 점검 묶음 100개: 정정 권고 68 · 유지 29 · 사람 확인 3)를 세어 올려 끝 화면에 남긴다.
- c4: '반박 · 보완' 표시를 점검선 위로 올렸다.
- c5: 제안 이름 128 → 100px. 음절이 바뀌는 시간을 0.55 → 0.42초로 줄였다. 중간 글자는 자모가 한 단계씩 바뀌는 연출이라 남겼다.
- 공통: 클립 구간의 작은 글씨를 챕터 제목으로 바꿨다(예: '조직변경 영향도' 아래 '사례 1').

## 반영하지 않은 것

- s03 글자 크기: 노드 25px, 행 23px로 1080p 기준 발표 화면에서 읽히는 크기다. 비평의 추정치(12~15px)는 320px 썸네일에서 잰 값이다.
- 장면 첫 프레임이 비어 보이는 시각(6·14·26·42초): 다음 장면이 막 들어오는 0.0초 프레임이다. 1초 간격 시트가 그 순간을 집었다.
