# 단위업무명·기록물철명 작성 관례

분류기준표 최종(안)의 기존 이름 699개와 `4-1 분류체계 정비 및 보존기간 적용 변경 이력`의 담당부서 의견 185종에서 뽑은 관례다.

## 1. 단위업무명

### 기존 이름의 통계

| 항목 | 값 |
| --- | --- |
| 길이 | 평균 10.5자, 중앙값 10자, 최소 2자, 최대 23자 |
| `관리`로 끝남 | 577개(83%) |
| 그 밖의 끝말 | 운영 19, 사업 12, 지원 6, 점검 5, 협력 4 |
| 가운뎃점(·) 사용 | 315개(45%) |
| ` 및 ` 사용 | 3개 |

### 구조

`대상(시설·제도·사업·시스템) + 행위(1~3개) + 관리`

| 기존 이름 | 대상 | 행위 |
| --- | --- | --- |
| 교육과정 기획·운영관리 | 교육과정 | 기획·운영 |
| 항행전자시설 장애·기술이력관리 | 항행전자시설 | 장애·기술이력 |
| 공직윤리 신고·점검·조치관리 | 공직윤리 | 신고·점검·조치 |
| 토목·조경시설 유지관리 | 토목·조경시설 | 유지 |
| 전자감사시스템·AI감사 운영관리 | 전자감사시스템·AI감사 | 운영 |
| 일상감사 관리 | 일상감사 | (없음) |

### 규칙

1. 명사구로 쓴다. 서술어·조사로 끝내지 않는다.
2. 대상이 분명하면 `관리`로 끝낸다. 사업·지원·협력처럼 행위 자체가 업무 이름이면 그 낱말로 끝내도 된다(예: `동반성장 지원사업`, `단체상해보험 운영`).
3. 나란히 놓는 낱말은 가운뎃점(·)으로 잇는다. ` 및 `는 쓰지 않는다.
4. 행위는 3개까지만 잇는다. 더 많으면 포괄하는 낱말(운영, 유지, 사후)로 줄인다.
5. 공사가 지정한 정식 명칭을 쓴다. 담당부서 의견 사례: `청사통신시설`을 `공항통신시설`로, 시스템은 `공항소음정보시스템`처럼 정식 이름으로 바꾸도록 요청했다.
6. 같은 종류의 업무를 여러 부서가 하면 대상 시설명을 앞에 붙여 부서 고유 업무로 구별한다. 사례: `관제전자시설`, `항행안전시설`을 `항행전자시설`로 바꿔 부서별 단위업무를 분리했다. `계류장관제업무 운영`, `계류장관제업무 안전관리`, `계류장관제업무 인력관리`처럼 같은 대상 아래 행위로 나눈다.
7. 업무 주기를 따라 나눌 수 있으면 주기 단계로 나눈다. 사례: 항행장비사업을 견적, 입찰, 계약, 수행 단계로 나누도록 요청했다.
8. 연도, 차수, 업체명, 개별 사업 건명, 괄호, 문서 처리 행위(알림, 제출, 요청, 보고)는 넣지 않는다. 개별 건은 기록물철 수준에서 다룬다.
9. 범위가 너무 넓은 이름(`업무관리`, `일반관리`)과 문서 한 종류만 가리키는 이름(`월간 실적보고`)을 피한다. 단위업무 하나에 기록물철 1~5개가 들어가는 크기가 알맞다.

## 2. 기록물철명

- 평균 13.7자. 단위업무 안에서 대상·단계·문서 성격으로 구분한다.
- 단위업무에 철이 하나뿐이면 단위업무명과 같은 이름으로 통일해도 된다(사례: "단위업무명 기록물철과 통일", `항행장비사업 전략 관리`).
- 철이 여러 개이면 단위업무명을 그대로 되풀이하지 않는다(사례: 단위업무명과 겹쳐 `라오스 PPP(LPIA)`를 `라오스 루앙프라방(LPIA)`로 변경).
- 포함하는 문서를 모두 가리킬 수 있는 포괄 명칭을 쓴다(사례: `환경질 관리` 안에 대기·수질·토양·폐기물 포함, `소음측정망 운영` 안에 측정분석·리포트·데이터관리 포함).
- 구분이 모호한 철은 합친다(사례: `기계시설 신설·개량공사`와 `기계시설 보수공사`는 성격 구분이 모호해 하나의 공사철로 요청). 보존기간이나 참고 기간이 다른 문서는 나눈다(사례: 민원은 과거 사례 참고를 위해 별도 철).
- 부서공통 성격의 문서(감사 수검, 국회 대응 등)를 고유 철에 넣을지 공통 철로 뺄지는 담당부서마다 의견이 달랐다. 초안에서는 고유 업무와 직접 이어지는 것만 포함하고 사유에 적는다.

## 3. 기록물철 설명

문형: `{대상}의 {행위·문서 종류 나열} 관련 자료를 관리하는 기록물철`

예시

- 전자감사시스템의 운영과 사용자·정보자원 관리, 기능 개선 요청 및 개발완료 통보, 시스템 정보 현행화와 취약점 점검 관련 자료를 관리하는 기록물철
- 공공기관 감사협회와 감사협의회 등 감사기구 간 교류·협력, 공동회의와 간담회, 교차감사 및 인력지원 협의, 우수기관 벤치마킹 관련 자료를 관리하는 기록물철

설명에 넣는 행위·문서 종류는 근거 군집의 대표제목에서 확인된 것만 쓴다. 평균 길이는 76자다.

## 4. 소기능

소기능은 단위업무의 바로 위 단계다. 대조 모드의 신설은 같은 부서 기존 소기능 가운데 맞는 것을 고르고, 없을 때만 `대상 + 관리` 형태로 새로 적는다. 초안 모드는 준용 참고 기준표의 소기능을 우선 쓴다.
