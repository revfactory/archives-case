# 영향도 보고서 목차

`output/{run}/영향도_보고서.md`는 다음 순서로 쓴다. 해당 내용이 없는 절은 "해당 없음"이라고 적고 지우지 않는다.

1. **요약** — 무엇이 바뀌는지 3문장 이내, 핵심 숫자 표(사건 수, 변경 대상 단위업무·기록물철 수, 확정안·검토필요 수, 신설 제안 수).
2. **조직변경 내용** — 사건별 표: 사건 ID, 유형, 요약, 근거, 확신도. 입력이 차수 비교인지 시나리오인지와 기준을 적는다.
3. **분류기준표 영향** — 사건별로 조치별 단위업무·기록물철 수, 변경 대상 기록물철의 보존기간 분포. 보존기간 30년 이상(준영구·영구 포함) 기록물철이 포함된 사건은 따로 표시한다.
4. **문서 규모** — 영향받는 부서의 연도별 생산·접수 문서 수. 실·단·공항 단위 전체 건수이며 단위업무별 건수가 아니라는 점, 준용·승계추정 부서 구분을 적는다.
5. **사람이 결정할 사항** — 검토필요 항목(검증 의견 포함), 검증이 지적한 누락, 미해결 항목, `확인필요` 질문을 결정 단위로 묶어 적는다.
6. **신설 단위업무 제안** — 제안 표와 검증 판정.
7. **분석 범위 밖** — 분석되지 않은 사건과 사유, 분류기준표에 대응 항목이 없는 부서.
8. **산출물 목록** — CSV 파일 경로와 각 파일의 용도, 적용 순서(확정안 검토 → 검토필요 결정 → 분류기준표 반영 → `kac-shared` 색인 재생성).
